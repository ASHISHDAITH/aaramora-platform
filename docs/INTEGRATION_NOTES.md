## Preserved boundaries
- No user accounts, backend, cloud sync, AI inference, analytics, advertising, push notifications, public posts or direct messages.
- No diagnosis quiz, medicine recommendation, supplement plan, cure claim, forced disclosure or engagement ranking.
- Community remains a future concept; do not enable user-generated posting until moderation and escalation operations are ready.
- Prototype interactions are local to the open page and do not persist personal notes.
- Quick Exit navigates to a blank page but does not erase browser history, network logs or shared-device activity.

## Current state
The static prototype and documentation are now in this repository. This is not a production Next.js application or a deployed clinical service. Clinical review, language review, accessibility and device testing, lived-experience co-design, privacy/security review, and crisis-information revalidation remain release gates.
