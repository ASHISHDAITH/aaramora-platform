# AARAMORA Reading Library Expansion

**Research and editorial snapshot: 24 November 2026**

This register supports `reading-library.html`. It is a curated set of source institutions and verified rights notes, not a claim that the entire internet, every repository, or every book has been scraped. The public-facing library links to publisher and institutional landing pages. It does not bypass DRM, paywalls, lending controls, login gates, repository permissions or download restrictions.

## Access model

| Access label | Meaning | Aaramora handling |
|---|---|---|
| Public-domain edition | Copyright has expired or the rights holder has dedicated the specified edition to the public domain in the relevant jurisdiction | Link to the exact catalogue/rights page; check territory and edition before mirroring |
| Open-licensed book | The book or identified part carries an explicit licence | Display exact licence/version, creator, source and attribution; observe NonCommercial, ShareAlike, no-derivatives and third-party exclusions |
| Verified text data | A specific text dataset has explicit redistribution conditions | Preserve the exact required content, provenance, attribution and notice; never infer that translations share the same terms |
| Read online | Institution permits online access; reuse permission may be absent or mixed | Link to source reader; do not copy text or files without permission |
| Library borrowing | A lender offers a time-limited loan or controlled digital use | Link to the borrowing flow; do not bypass expiry or access controls |
| Publisher/library access | Copyrighted commercial title | Link to publisher, author or authorised library catalogue; no unofficial mirrors |

## Search behaviour

The page-level search filters the visible resource cards by their rendered text. It does not query external services, make network requests, create user profiles, or save search terms. Search is a client-side convenience, not a full catalogue index or semantic search engine.

## Collection and maintenance rules

1. Record exact title, author/translator/editor, language, edition, publisher/institution, source URL and date checked.
2. Record book-level or text-level licence/version and the canonical rights URL. A repository root licence is not enough.
3. Check covers, photos, diagrams, maps, typography, marginalia and third-party inserts separately.
4. Do not mass-scrape Project Gutenberg or Open Library HTML; use their stated catalogue/API or bulk-data routes and rate/identification guidance where appropriate.
5. Store metadata only when its terms allow it. A database record is not a copy of the book.
6. Never bypass paywalls, DRM, private repositories, account gates, lending expiry or download restrictions.
7. Prefer publisher-hosted files and readers so corrections, errata and replacement editions remain under source control.
8. Recheck URLs, editions, and rights before production release and at a documented review interval.
9. Do not send any restricted book text into Aaramora's AI or research corpus. Respect specific AI-training/ingestion exclusions, including the current OpenStax Psychology 2e preface notice.
10. Keep content in original language where possible; any translation, transliteration, paraphrase or commentary gets its own provenance and rights record.

## Review limitations

This is an initial editorial/source register, not legal advice or a complete global clearance opinion. Public-domain status can vary by country. Open licences have conditions and may exclude third-party portions. Religious texts need respectful handling and appropriate review by readers knowledgeable in the relevant language and tradition. New entries require a final link check and rights review before they are described as downloadable or reusable.

### Automation and review

`scripts/check_catalogue.py` validates required source, access, rights, language and review-date fields. `scripts/check_library_links.py` performs polite HEAD/range checks against the metadata source URLs only; no book text, scans or full page bodies are downloaded. The weekly workflow flags confirmed 404/410 responses and reports blocks or transient failures as inconclusive. A human editor still needs to review source availability, edition accuracy, cultural wording and licences before describing an item as freely downloadable or reusable.

### Editorial limits
- A link to a source page is not a statement that the entire work is free to redistribute.
- Project Gutenberg records explicitly say public domain in the United States; the catalogue does not extend that claim to every territory.
- The Bengali Gitanjali 1913 source page identifies the publisher/imprint and says US public-domain status is based on pre-1931 publication; it separately explains other territorial rules. The original work and Wikimedia contributor layer must not be collapsed into a single worldwide licence.
- Project Madurai's Tirukkural UTF-8 page carries © Project Madurai 1998–2000 and permits redistribution of that exact file provided the header page is retained. Do not remove the header or extend the permission to other editions.
- The Punjabi Guru Granth Sahib entry is one selected folio/page from a digital PDF, not a full-scripture digital edition. The page says the transcription is CC BY-SA; image/scan and wider database rights are separate.
- The Marathi Jnaneshwari page warns about a duplicate passage/chapter issue. AARAMORA marks it as a source link, not a checked critical edition.
- The Odia Bhagabata entry links only to the first Skandha page. Do not imply it represents all skandhas.
- Hindawi says its licensed Arabic books remain free to read and download via Safahat. This is access at the publisher's platform, not a right to mirror the books.
- BaniDB remains linked only. No Gurbani data has been copied or integrated.

### Native-review release gate
All 26 records currently have editorialReview.nativeLanguage=pending, editorialReview.culturalContext=pending, and editorialReview.accessibility=pending. These values can only be changed after named native-language, tradition/context, and assistive-technology reviewers document the specific edition they checked. Metadata verification alone cannot approve pronunciation, translation fidelity, theological wording, OCR quality or reading accessibility.



### Metadata link-check implementation update
The metadata-only link checker now percent-encodes non-ASCII URL paths before HTTP requests. This supports pages whose URL paths contain Devanagari, Bengali, Gurmukhi, Arabic-derived, Odia and other Unicode scripts. It still uses HEAD first and a one-byte range request only for selected HEAD blocks; no source page body or book file is downloaded or parsed.
