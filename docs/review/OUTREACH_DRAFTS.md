## 2. Religious / cultural-context reviewer

**Subject:** Request for a scoped cultural-context review of a linked text record

Dear Professor / Review Team,

AARAMORA is documenting a reading-library link to [work / edition / source page]. We are asking for a narrow review of the record's cultural/tradition label and short explanatory description, not for an endorsement of the website or a religious ruling.

Please review whether the record:
- identifies the type of work and tradition accurately;
- distinguishes source text, commentary, translation and edition;
- avoids presenting one interpretation as universal;
- acknowledges relevant variants, disputed points or limitations; and
- uses respectful, non-proselytising language.

Please advise availability, expertise, expected fee/honorarium, and whether you can provide a short written decision with sources. We will keep the status pending until a signed report is received.

Regards,  
AARAMORA Reading Library

## 3. Accessibility audit request

Dear Accessibility Testing Team,
