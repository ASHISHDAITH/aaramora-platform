## English draft for review

Thank you for telling this site. This is a moment to involve a real person. If you or someone else is in immediate danger, call **112** now or go to an emergency department. For mental-health support in India, call **Tele-MANAS 14416**. If it is safe to do so, move near a trusted person and tell them you need them to stay with you; put distance between yourself and anything you might use to hurt yourself. This site is not monitored in real time and cannot contact emergency services for you.

## Product behaviour required around this text

- Do not ask questions about methods, plans, quantities, access or locations.
- Do not send the crisis message through an LLM. The deterministic safety layer must return the fixed approved text.
- Keep the 112 and 14416 call links visible.
- Do not imply that a human is monitoring chats or that the site can dispatch help.
- Keep the static Get Help page available if the chat is disabled, the network fails or the model is unavailable.
- Do not translate this draft for public use until a named native-language reviewer and clinician approve each version.
- This is a candidate for review, not clinical guidance or an approved script.
