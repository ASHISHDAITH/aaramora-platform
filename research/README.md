# Research bundle

This folder preserves the original global website benchmark and concept material.

- `benchmark50.csv` — 50 candidate websites, categories and research focus. Treat this as a shortlist, not a verified ranking.
- `mental-health-website-benchmark-report.md` — product concept, feature strategy, sitemap, community safety and roadmap.
- `visual-report.html` — browser-viewable visual concept report. Its SVGs are original concept illustrations, not competitor screenshots.
- `../assets/` — Healing Garden, Safe Corner and Thought River SVG assets.

Before calling this a ranked benchmark, verify each official URL, current service status, current features, languages, privacy practices and screenshots. Do not infer current functionality from this candidate list.
