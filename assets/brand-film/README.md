# Brand Film Assets

The two unique approved MP4 exports are committed in this directory:

- `aaramora-master-16x9.mp4` — 16:9 website master.
- `aaramora-instagram-9x16.mp4` — 9:16 Instagram edit.

The third supplied file labelled `CLEAN_NO_ADDED_AUDIO` is byte-identical to the landscape master and contains AAC audio, so it is not stored as a separate silent master.

See [the export manifest](../../docs/AARAMORA_BRAND_FILM_ASSETS.md) for technical metadata, checksums, campaign order and usage notes.
